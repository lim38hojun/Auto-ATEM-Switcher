# ATEM Mini Pro 10-Split Multiview 1080p Coordinate Reference

ATEM Mini Pro의 HDMI OUT 기본 멀티뷰(1920×1080) 레이아웃은 상단 2분할(Preview / Program), 중단 4분할(Camera 1 ~ Camera 4), 하단 4분할(Media Player, Streaming, Recording, Audio)의 **총 10분할 그리드**로 구성됩니다.

## 1. 전체 그리드 레이아웃 (1920 × 1080 기준)

```text
+-----------------------------------------------+-----------------------------------------------+
|                                               |                                               |
|                 PREVIEW (PVW)                 |                 PROGRAM (PGM)                 |
|              (0, 0) ~ (960, 540)              |             (960, 0) ~ (1920, 540)            |
|                                               |                                               |
+-----------------------+-----------------------+-----------------------+-----------------------+
|         CAM 1         |         CAM 2         |         CAM 3         |         CAM 4         |
|   (0,540)~(480,810)   |  (480,540)~(960,810)  | (960,540)~(1440,810)  | (1440,540)~(1920,810) |
+-----------------------+-----------------------+-----------------------+-----------------------+
|     MEDIA PLAYER      |    STREAMING STATUS   |    RECORDING STATUS   |      AUDIO METERS     |
|   (0,810)~(480,1080)  |  (480,810)~(960,1080) | (960,810)~(1440,1080) | (1440,810)~(1920,1080)|
+-----------------------+-----------------------+-----------------------+-----------------------+
```

## 2. 카메라 1~4 정밀 크롭 좌표표 (Safe Inner ROI 포함)

각 카메라 셀의 외곽 테두리(Tally Border: 빨강/초록 3px)와 하단 라벨 바(`Cam 1` 텍스트 및 오디오 미터)가 OpenCV 분석에 포함되지 않도록 `inner_margin`을 적용한 권장 슬라이싱 좌표입니다.

| 채널 | 전체 셀 영역 `(x, y, w, h)` | 테두리/라벨 제외 분석용 Safe ROI `(x, y, w, h)` | NumPy 슬라이싱 `frame[y1:y2, x1:x2]` |
| :--- | :--- | :--- | :--- |
| **Cam 1** | `(0, 540, 480, 270)` | `(8, 546, 464, 236)` | `frame[546:782, 8:472]` |
| **Cam 2** | `(480, 540, 480, 270)` | `(488, 546, 464, 236)` | `frame[546:782, 488:952]` |
| **Cam 3** | `(960, 540, 480, 270)` | `(968, 546, 464, 236)` | `frame[546:782, 968:1432]` |
| **Cam 4** | `(1440, 540, 480, 270)` | `(1448, 546, 464, 236)` | `frame[546:782, 1448:1912]` |
